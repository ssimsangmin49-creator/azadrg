# AZADrg

*Rather than doing some work for the good of the world?*

AZAD Research Group (AZADrg) is a non-commercial initiative dedicated to sharing AFC/SSOF technology for local implementation.

## License & Non-Commercial Use

Website source code is available under the MIT License.

AFC/SSOF technical documentation and related materials are shared exclusively for non-commercial purposes, including research, education, local construction, operation, and field validation.

AZADrg does not sell equipment, charge licensing fees, or collect royalties.

**We do not export equipment. We share capability.**
